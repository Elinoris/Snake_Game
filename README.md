# 🐍 Snake Game

משחק נחש קלאסי שנבנה ב-Java באמצעות Swing, כחלק ממטלת קורס לפיתוח משחק דו-ממדי עם ניהול התנגשויות, שליטה במקלדת ותכנות מקבילי באמצעות `Thread`.

## תצוגה כללית

המשחק כולל מסך פתיחה, מסך הוראות, ולולאת משחק המנוהלת על ידי thread נפרד (ולא `Timer`), עם מערכת ניקוד ורמות קושי שעולות ככל שהניקוד גדל.

## תכונות עיקריות

- **מסך פתיחה** – בחירה בין "התחל משחק" ל"הוראות".
- **מסך הוראות** – הסבר על מטרת המשחק, מקשי השליטה וחוקי הניקוד.
- **לולאת משחק על גבי Thread ייעודי** – תנועת הנחש מתעדכנת בזמן אמת ללא שימוש ב-`Timer`.
- **זיהוי התנגשויות** – פגיעה בקיר או בגוף הנחש עצמו מסיימת את המשחק.
- **מערכת ניקוד** – 10 נקודות על כל פריט מזון שנאכל.
- **רמות קושי דינמיות** – מהירות המשחק עולה ככל שהניקוד גבוה יותר (6 רמות קושי).
- **מסך Game Over** – מציג את הניקוד הסופי עם אפשרות להתחיל מחדש באמצעות מקש `SPACE`.

## מבנה הפרויקט

```
Snake_Game-main/
└── src/
    ├── Main.java               # נקודת הכניסה לתוכנית
    ├── GameFrame.java          # החלון הראשי, מנהל מעבר בין המסכים
    ├── StartPanel.java         # מסך הפתיחה
    ├── InstructionsPanel.java  # מסך ההוראות
    ├── GamePanel.java          # לוגיקת המשחק, לולאת ה-Thread והציור
    ├── GameObject.java         # מחלקת אב אבסטרקטית (ירושה/פולימורפיזם) ל-Snake ו-Food
    ├── Snake.java              # מחלקת הנחש – תנועה, גדילה, זיהוי התנגשות (יורשת מ-GameObject)
    └── Food.java               # מחלקת המזון – מיקום וציור (יורשת מ-GameObject)
```

## ירושה ופולימורפיזם

`Snake` ו-`Food` יורשות משתיהן ממחלקת האב האבסטרקטית `GameObject`, שמגדירה מתודת `draw(Graphics2D)` אבסטרקטית. ב-`GamePanel` הציור מתבצע פולימורפית:

```java
GameObject[] gameObjects = { snake, food };
for (GameObject obj : gameObjects) {
    obj.draw(g2); // כל אובייקט מצייר את עצמו לפי המימוש שלו
}
```

## דרישות מערכת

- JDK 8 ומעלה (המשחק משתמש ב-Swing שהוא חלק מה-JDK הסטנדרטי, ללא תלויות חיצוניות).

## הרצת המשחק

### מ-IDE (IntelliJ / Eclipse וכו')
1. פתחו את התיקייה כפרויקט Java.
2. הריצו את `Main.java`.

### משורת הפקודה
```bash
cd src
javac *.java
java Main
```

## מקשי שליטה

| מקש | פעולה |
|-----|--------|
| ↑ | תנועה למעלה |
| ↓ | תנועה למטה |
| ← | תנועה שמאלה |
| → | תנועה ימינה |
| SPACE | התחלה מחדש (לאחר Game Over) |

## חוקי המשחק

- כל פריט מזון שנאכל מוסיף 10 נקודות ומגדיל את הנחש.
- ככל שהניקוד עולה, מהירות המשחק (ורמת הקושי) עולה בהתאם.
- התנגשות בקיר או בגוף הנחש מסיימת את המשחק.
